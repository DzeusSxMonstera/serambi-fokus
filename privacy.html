Kebijakan Privasi

Terakhir diperbarui: 8 November 2026

Ringkasnya

Atlas Alam tidak memiliki akun pengguna, tidak memiliki server sendiri, dan tidak mengumpulkan data pribadi. Semua yang kamu simpan berada di browser perangkatmu sendiri.

Data yang disimpan di perangkatmu

Disimpan lokal di browser (localStorage dan IndexedDB), tidak dikirim ke kami:

  • pengaturan tampilan, tema, cuaca, neon, dan posisi widget;
  • catatan, task terjadwal, dan teks running text beserta logo sponsor yang kamu unggah;
  • foto latar, file MP3, file adzan, dan file screensaver yang kamu pilih;
  • lokasi sholat (kota bawaan atau koordinat yang kamu izinkan), ukuran ikan akuarium, dan pilihan Al-Qur'an terakhir.

Data ini terikat pada browser dan alamat situs. Kamu bisa memindahkannya lewat Workspace → Pengaturan → Cadangan data, atau menghapusnya lewat pengaturan data situs di browsermu.

Layanan pihak ketiga yang dipanggil browsermu

Saat widget tertentu dinyalakan, browsermu langsung meminta data dari layanan berikut. Layanan tersebut dapat melihat alamat IP dan informasi teknis permintaan sesuai kebijakan mereka masing-masing:

LayananUntuk apa
api.alquran.cloud, islamic.networkTeks Al-Qur'an, terjemahan, audio per ayat
mp3quran.netDaftar qari dan audio per surah
api.myquran.comHadis acak

Jadwal sholat, arah kiblat, dan kalender Hijriah dihitung di perangkatmu tanpa memanggil layanan luar.

Izin perangkat

  • Lokasi: hanya diminta saat kamu menekan "Pakai lokasi saya". Koordinat dipakai di perangkatmu untuk menghitung waktu sholat dan arah kiblat.
  • Notifikasi: hanya diminta saat kamu mengaktifkan pengingat sholat.
  • Sensor arah: hanya diminta saat kamu mengaktifkan kompas.

Hosting dan tautan keluar

Penyedia hosting situs ini dapat mencatat kunjungan sesuai kebijakan mereka. Tautan sosial di bagian bawah halaman membuka situs lain yang punya kebijakan privasinya sendiri.

Anak-anak

Aplikasi ini tidak meminta data pribadi dari siapa pun, termasuk anak-anak.
